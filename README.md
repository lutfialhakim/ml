# Klasifikasi Ikan — SVM & Perceptron

Aplikasi Streamlit untuk memprediksi jenis ikan menggunakan dua model machine learning yang sudah dilatih: **SVM** dan **Perceptron** (file model tersimpan di folder `fish/`).

## Teknologi

- Python, Streamlit
- scikit-learn, pandas, NumPy, joblib

## Menjalankan aplikasi

```bash
pip install streamlit pandas numpy scikit-learn joblib
streamlit run app.py
```
